# v0.1.0

PowerShell SSH Bridge includes a complete editable workspace and an installable Agent
Skill. The first release targets Codex on Windows with PowerShell and OpenSSH.

- Environment discovery, guided key setup, pinned host verification, remote commands,
  file transfer, local forwarding and stage-based diagnostics.
- Complete English and Chinese guides, sanitized case study and research attribution.
- Local and opt-in live tests, standard-library Python build/install tooling,
  reproducible runtime/workspace ZIPs and SHA256 manifests.
- MIT license. Runtime compatibility evidence is recorded in `references/verification.md`.

Download `*-skill.zip` to install; download `*-workspace.zip` or clone the repository
to develop. Extract into a fresh directory and review the README. Verify the ZIP's
SHA256 against `SHA256SUMS` from this release.

## 简体中文

PowerShell SSH Bridge 提供可安装的 Agent Skill 和完整可编辑开发工作区，首版以
Windows 上的 Codex、PowerShell 和 OpenSSH 为验证目标。

- 附本地测试、按需实机测试、仅依赖 Python 标准库的构建与安装工具，以及可重复构建的两种 ZIP 和校验清单。
- 使用 MIT 许可证；运行验证依据见 `references/verification.zh-CN.md`。

安装下载 `*-skill.zip`；二次开发下载 `*-workspace.zip` 或克隆仓库。解压到新目录后阅读 README，
