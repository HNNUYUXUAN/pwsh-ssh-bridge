## 实现过程中解决的问题

- 沙箱账户能生成密钥但无法设置所需私钥 ACL。脚本报告失败，获准的本机用户上下文通过 ACL 验证。
- 子 PowerShell 的重定向 JSON 继承本地代码页，造成中文乱码。模块现已显式设置 UTF-8，实机中文测试通过。
- Windows OpenSSH 在重复占用本地转发端口时，第二个进程未按预期退出。
  Helper 增加排他回环端口可用性检查，保留 SSH 转发失败选项，并要求验证实际服务。
  该预检查不是原子端口预留，调用方仍须检查真实监听状态。

## 复现方式

在可信 PowerShell 7 终端中使用私有临时目录：

```powershell
pwsh -NoProfile -File ./tests/Test-Local.ps1 -WorkDirectory '<私有临时目录>'
pwsh -NoProfile -File ./tests/Test-Live.ps1 `
  -ConfigFile '<已审阅配置>/ssh_config' -Alias lab -WorkDirectory '<私有临时目录>'
```

实机隧道测试假定远端回环地址的 22 端口提供 SSH，临时测试需要 Linux 的 `sha256sum`、`stat`、`mktemp` 和 `sh`。
换设备运行前审阅测试。测试读取获准配置，仅创建/删除其唯一临时测试文件。
本地临时目录保留一次性密钥和诊断结果，应保持私有，在不再需要时清理。
